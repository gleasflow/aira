# AIRA Studio AI

Platform peluncur link dan katalog tools kreatif AI (Tools Affiliate, Tools Animasi, Tools Cerita) dengan antarmuka Light Mode yang bersih, menu popup mengambang di sisi kiri, workspace kanan yang lega, halaman login otentikasi, serta dashboard admin untuk pengelolaan user dan link.

## Fitur Utama

- **Nama Aplikasi**: AIRA Studio AI
- **Desain Light Mode**: Tampilan bersih, kontras tinggi, dan nyaman untuk penggunaan harian.
- **Sidebar Rail & Menu Popup Kiri**:
  - Bilah ikon samping ramping (72px) yang menjaga area kerja tetap maksimal.
  - Menu flyout popup mengambang dengan pencarian instan, filter sub-kategori, dan opsi pin/dock.
  - Tombol **Mode Lega (Zen Mode)** untuk menyembunyikan navigasi demi ruang kerja 100% penuh.
- **Link Launcher Cerdas**:
  - Kartu link launcher lengkap dengan gambar thumbnail (atau banner gradasi), tag kategori, deskripsi detail, serta jumlah klik real-time.
  - Tombol "Luncurkan" (buka link dan lacak jumlah klik).
  - Tombol salin link dengan feedback visual.
  - Fitur simpan/bookmark ke koleksi favorit.
- **Kategori Menu Khusus**:
  - **Tools Affiliate**: Pelacak UTM, kalkulator komisi, trend finder TikTok Shop, dan automasi e-commerce.
  - **Tools Animasi**: AI 3D mocap, generator motion video sinematik, storyboard pro, dan lip-sync karakter.
  - **Tools Cerita**: Novel worldbuilding, skenario film digital, plot twist generator, dan laboratorium dialog persona.
- **Halaman Login (Login Page)**:
  - Form login email & password.
  - Akses demo instan satu klik untuk peran Administrator dan Member.
  - Informasi profil terdaftar dan tombol logout.
- **Dashboard Admin**:
  - **Kelola Link**: Tambah link baru, edit link yang ada, hapus link, dan pantau total peluncuran.
  - **Kelola User**: Tambah pengguna, ganti peran (Admin / Kreator / Member), ubah status akun (Aktif / Ditangguhkan), dan hapus pengguna.
  - Ringkasan metrik analitik (Total Link, Total Klik, Pengguna Aktif, Kategori Terpopuler).

## Teknologi

- React 19 + TypeScript
- Vite 6 (Port 3000)
- Tailwind CSS
- Lucide React Icons
- LocalStorage Data Persistence
